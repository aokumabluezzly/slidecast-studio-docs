🛡️ OVERVIEW

まず結論

こんにちは。

SlideCast Studioは、スライドとナレーションを組み合わせて、スライド動画を作るアプリです。APIキーなしでも、用意した画像・台本・音声を取り込んで動画を作れます。アプリ内で台本や音声をAI生成するときには、ご自身のAPIキーを使う方法もあります。

「作ったスライドはどこかに送られる？」「APIキーを入れて大丈夫？」「料金が勝手に増えない？」と気になる方もいると思います。

SlideCast Studioは開発初期から、作品・APIキー・料金の扱いを、いちばん気をつけて作ってきました。

この記事では、その仕組みと、なぜそうしているのかをまとめてご紹介します。すでにお使いの方も、購入を迷っている方も、判断の材料にしていただけたらうれしいです。

💾セキュリティ作品は、あなたのブラウザの中にあります

作ったプロジェクトや、登録した画像・音声・BGMなどの素材は、あなたのブラウザの中に保存されます。GAS版でも、ローカルHTML版でも同じです。

※補足：作品や素材の保存には、ブラウザ内のデータベース「IndexedDB」を使っています。

作者（私）の側にはサーバーがないので、作品を作者（私）へ送る仕組みがそもそもありません。

なぜこうしているか

作品やデータをどこかのサーバーに集める仕組みだと、そのサーバーが攻撃されたり、設定を誤ったりしたときに、たくさんの人の作品が一度に流出するおそれがあります。

SlideCast Studioは、はじめから預からない作りにしているので、作者（私）の側から作品が漏れることはありません。

通信するのは、次のときだけです

アプリが外と通信するのは、次のときだけです。

  • アプリを開いたとき
    GAS版では、アプリ本体を、ご自身のGoogleアカウントにデプロイしたGASから取得します。また、Google Fontsからフォントを取得します（IPアドレスはGoogleに届きますが、作品の内容は送りません）

  • 台本を自動で作るとき
    スライド画像と、選んだ設定・話者名をGemini APIへ

  • 音声を作るとき
    セリフの文章をGemini APIまたはGoogle Cloud Text-to-Speechへ

  • APIキーの確認・声の一覧を取るとき
    APIキーをGoogleへ（料金はかかりません）

  • リンクをクリックしたとき
    そのリンク先へ移動します

Googleへ送った内容がGoogle側でどう扱われるかは、Googleに送った内容の扱い（無料と有料で変わります）で解説します。無料枠と有料枠で扱いが変わるので、あわせてご覧ください。

v4.4からは、この内容をアプリ内のヘルプにある「通信と安全」タブでも見られるようにしました。

🔑セキュリティAPIキーは、ブラウザ内で保持し、Googleへの認証に使います

なぜ気をつける必要があるか

APIキーは、Googleのサービスを使うときに、利用するプロジェクトを識別するための鍵のようなものです。料金の有無は、そのプロジェクトの課金設定や利用内容によって決まります。有料枠のキーが漏れると、他の人に使われた分の料金が請求されるおそれがあります。

そのため、SlideCast Studioでは、キーが外に出る経路をできるだけ作らないようにしています。

※Google AI StudioやGemini、ChatGPTなど外部で台本や音声を生成する場合はAPIキーなしでも利用可能です

保存するかどうかを選べます

APIキーの保存方法は、設定 > 音声の「この端末に保存しない（セッションのみ）」で選べます。

ON（おすすめ）：セッション限定で保持し、通常はタブを閉じるとキーが消えます。ただし、ブラウザの復元機能によって保持される場合があります。

OFF：この端末のブラウザに保存され、次回もそのまま使えます。

自分だけが使うPCならOFFでも便利に使えます。共有PCでは、ONになっていることを確認してください。以前からキーを保存していた方は、OFFになっている場合があります。利用後にキーを確実に消したいときは、設定 > 音声の「消去」を使ってください。

ブラウザの拡張機能に注意

ブラウザの拡張機能の中には、「すべてのサイトのデータの読み取りと変更」ができる権限を持つものがあります。この権限があると、開いているページの入力欄や、ブラウザに保存されたデータを読むことができます。

そのため、悪意のある拡張機能が入っていると、画面に入れたAPIキーを読み取られるおそれがあります。 はじめは問題のなかった拡張機能が、あとから他の人の手に渡ったり、乗っ取られたりして、悪意のある動きをするようになる例もあります。

これはSlideCast Studioに限らず、ブラウザでAPIキーやパスワードを扱うすべてのサイトに共通する注意点で、アプリの側だけでは防ぎきれません。次のことを心がけてください。

  • 拡張機能は、公式ストアから、信頼できる提供元のものだけを入れる

  • 使っていない拡張機能は削除する

  • 「すべてのサイトのデータの読み取りと変更」の権限を持つ拡張機能は、本当に必要か見直す

  • 気になる場合は、拡張機能を入れていない別のブラウザ（またはChromeの別プロフィール）でSlideCast Studioを使う

APIキーを「セッションのみ」にしておくと、端末に長く保存することを避けられます。ただし、画面を開いている間は読み取られるおそれがあるので、拡張機能の見直しとあわせて、有料枠を使う方は料金の上限は、Google側で決めておくと安心ですの月額上限も設定しておくと安心です。

保存やバックアップには入りません

APIキーは、次のどれにも入りません。

  • プロジェクトの保存データ

  • バックアップファイル

  • プリセット

バックアップやプロジェクトは、PCの引っ越しや、人との共有に使うことがあります。そこにキーが入っていると、ファイルを渡した相手にキーまで渡ってしまいます。そうならないように、キーはどのファイルにも書き出さないようにしています。

URLにキーを載せません

APIキーは、URLには載せず、Googleへのリクエストの中（ヘッダー）に入れて送ります。

URLは、閲覧の履歴や通信の記録に残りやすい部分です。そこにキーを載せないことで、思わぬところにキーが残るのを防いでいます。

消したいとき

ダッシュボードのヘッダーの「データを初期化」（ゴミ箱アイコン）で「APIキー・その他のローカル設定」を選ぶと、ブラウザに保存したキーを消せます。

⏸️セキュリティ料金が増えすぎないための仕組み

なぜ気をつける必要があるか

SlideCast Studioで、APIキーを使って台本や音声を生成するときは、あなたのAPIキーの利用量を使います。

うっかり大量に実行したり、エラーで同じ処理が何度も繰り返されたりすると、気づかないうちに料金が増えてしまうおそれがあります。そうならないように、次の仕組みを入れています。

音声の一括生成

  • 1件ずつ順番に生成します（同時にたくさん送りません）

  • 音声生成が3件連続で失敗すると、一括生成を自動停止します。1件の生成では、エラーの種類に応じて最大3回の試行を行います

  • 生成中は「緊急停止」ボタンで、次の音声の生成へ進むのを止められます。実行中の1件は、再試行を含めて処理が続く場合があります

  • 実行前に、対象の件数と文字数を表示します

台本の自動生成

  • 実行前に、スライド画像をGeminiへ送ることを画面に表示します

  • v4.4からは、次のようにしました

    • 実行中に「中断」ボタンで止められます

    • 約3分たっても終わらないときは、「待ち続ける」か「中断する」かを選べます

    • スライドが30枚を超えるときは、実行前に確認が出ます

    • 台本生成の画面を閉じると、通信も止まります

これらは「確認を挟む・止められる」ための仕組みで、件数や枚数そのものは制限していません。料金の上限をしっかり決めておきたい方は、次の章の月額上限をおすすめします。

💰セキュリティ料金の上限は、Google側で決めておくと安心です

アプリ側の確認に加えて、Google AI Studioの「利用額」ページで、プロジェクトごとにGemini APIの月額上限を設定できます。上限に達すると、そのプロジェクトのGemini APIの利用が一時停止します。

アプリ側の仕組みは、SlideCast Studioの中での操作にしか効きません。Google側の月額上限は、同じプロジェクトのキーを他の場所で使った分も含め、Gemini APIの利用額に適用されます。有料枠を使う方は設定しておくことをおすすめします。Google Cloud Text-to-Speechなど、ほかのサービスの料金には、この上限は適用されません。

以下は補足として知っておくとよい点です。

  • 月額上限は実験的な機能です。集計には約10分の遅れがあり、長時間の処理などでも設定額を超える場合があります。設定額を絶対に超えない保証ではありません

  • 無料枠のプロジェクトには設定できません（無料枠は料金がかからない代わりに、使える量に制限があります）

  • Google Cloud Text-to-Speechを使う場合は、Google Cloudコンソールの「予算とアラート」で通知を設定できます（こちらは通知だけで、自動では止まりません）

v4.4からは、アプリの設定 > 音声にも、この案内と公式ページへのリンクを置いています。

🔍セキュリティGoogleに送った内容の扱い（無料と有料で変わります）

台本や音声を作るとき、スライド画像やセリフはGoogleへ送られます。その内容の扱いは、Google側の規約で決まっていて、無料枠と有料枠で大きく変わります（2026年9月30日時点の公式情報です）。

Gemini API の無料枠

  • 送った内容は、Googleの製品の改善（AIの学習を含む）に使われます

  • Googleの品質確認の担当者（レビュアー）が、内容を読むことがあります。 担当者が見る前に、あなたのGoogleアカウントやAPIキーとの結び付きは外されます

  • Googleは、無料枠に機密情報・個人情報を送らないよう案内しています

Gemini API の有料枠（請求先を設定したプロジェクトのキー）

  • 送った内容は、AIの学習を含む、Googleの製品の改善には使われません

  • ただし、不正利用の検知や法律上の対応のため、一定期間は記録されます

Google Cloud Text-to-Speech

入力した文章は記録されません

どうすればいいか

  • 機密情報や個人情報を含む資料を、無料枠で送るのは避けてください

  • 社内資料などを扱うときは、有料枠のキーを使うか、AIに送らないようにしてください

この注意は、設定 > 音声に表示しています。v4.4からは、台本生成の画面にも表示するようにしました。

規約は変わることがあります。最新の内容は、公式ページでご確認ください。

🧩セキュリティGemini Canvas のアプリ4つについて

SlideCast Studioと一緒に使う、Gemini Canvas上のアプリ4つ（Bundle Builder / MouthLoop / AI CODE MOVIE STUDIO / AI CODE BGM STUDIO）も、同じ考え方で作っています。

  • Geminiアプリの中で動き、AI生成のための送信先はGeminiです。作者（私）のサーバーへは送りません。部品の読み込みでは、外部のプログラムに頼りすぎない作り（サプライチェーン攻撃への備え）に記載したCDNへの通信もあります

  • 基本の使い方では、APIキーは不要です

  • AI CODE BGM STUDIO は、入力した内容をご自身のブラウザにだけ保存します

  • MouthLoop は、作業内容を保存しません。画面を閉じると消えるので、完成したキャラパックはZIPで保存してください

Bundle Builder でAPIキーを使う場合

Bundle Builderは、標準モデルなら通常APIキーなしで動きます。それ以外のモデルを使う場合や、API設定の「キーなしで動くモデルにもAPIキーを使う」をONにした場合は、ご自身のGemini APIキーで実行します。

  • 入れたキーは、ページを開いている間だけ保持し、端末には保存しません

  • キーはURLに載せず、ヘッダーで送ります

  • キーを使った生成は、あなたのキーの料金の対象になり、送った内容の扱いはGoogleに送った内容の扱い（無料と有料で変わります）の無料枠・有料枠の説明と同じです

入力した内容の扱い

Googleの案内では、ユーザーが作ったCanvasアプリの場合、アプリの作成者が、共有されたデータを見たり保存したりできると説明されています。私のアプリ4つには、入力した内容を作者（私）へ送ったり、作者（私）の側に保存したりする処理は入っていません。

以下では、Geminiでのチャットに関するデータの扱いを説明します。Canvasアプリ内での入力や生成内容にも同じ設定が当てはまるかは、Googleの公式情報には明記されていません。

個人のGoogleアカウントの場合

  • 「アクティビティの保存」がONだと、入力が学習に使われることがあり、一部はGoogleの担当者（Googleが委託した人を含む）が読む可能性があります

  • OFFにすると、その後のチャットは、Googleへフィードバックを送らない限りAIモデルの学習には使われません。処理や安全対策のため72時間保持され、その目的で人が確認する場合はあります

仕事用・学校用のアカウント（Google Workspace）の場合

  • Googleは、あなたの許可なく、チャットやアップロードしたファイルを人が読んだり、AIの学習に使ったりしないと説明しています

  • ただし、使える機能や扱いは組織の契約・設定によって変わることがあるので、詳しくは組織の管理者にご確認ください

この場合、APIの無料枠・有料枠の違いは関係しません。

🛡️セキュリティ外部のプログラムに頼りすぎない作り（サプライチェーン攻撃への備え）

サプライチェーン攻撃とは

多くのアプリは、PDFの読み込みやZIPの作成などを、公開されている部品（ライブラリ）を組み合わせて作っています。

サプライチェーン攻撃は、アプリそのものではなく、この部品や、部品の配布元がハッキングされて、悪いプログラムを混ぜられる攻撃です。部品はアプリの中で動くので、混ぜられたプログラムが、画面に入れたAPIキーや作品を盗み出すおそれがあります。

特に、アプリを開くたびに部品をCDN（部品をネットで配る仕組み）から読み込むアプリは、配布元のファイルが書き換えられると、その瞬間から使っている全員が影響を受けます。またCDNが止まれば、アプリも動かなくなります。

SlideCast Studio 本体の備え

  • 本体で使う部品は配布物に同梱しています。GAS版ではご自身のGoogleアカウントにデプロイしたGASから、ローカルHTML版では手元の配布ファイルから読み込みます。外部CDNからは取得しないため、CDNのファイルがあとから書き換えられたり、CDNが停止したりしても、同梱した部品には影響しません

  • 部品は版を固定して入れています。知らないうちに新しい版に入れ替わることはありません

  • 部品に既知の問題が見つかったときは、内容を確認し、必要に応じて修正された版に更新しています

  • フォントはGoogle Fontsから取得します。外部CDNからプログラムを取得することはありません

Gemini Canvas のアプリの備え

Canvasのアプリは、1つのファイルの中に部品をすべて入れることができないため、Bundle Builder と AI CODE MOVIE STUDIO（3D演出を使うときだけ）は、必要な部品を公開のCDN（cdnjs）から読み込みます。そのため、次の2つの対策をしています。

  • 版を固定する：「最新版」ではなく、決まった版を指定して読み込みます。配布元に新しい版が置かれても、勝手に切り替わりません

  • 中身の指紋を照合する：読み込む部品のファイルが、あらかじめ記録しておいた「指紋」（ファイルの中身から計算した値）と一致するかを、ブラウザが確かめます。1文字でも書き換えられていれば指紋が変わるので、ブラウザはその部品を動かしません

※補足：スクリプトの読み込みには、SRI（Subresource Integrity）を使っています。ハッシュ値（中身の指紋）を照合し、想定と異なるファイルの実行を防ぐブラウザの機能です。

✅セキュリティ安心して使うためにできること

最後に、利用する側でできることをまとめます。

  • Google AI Studioで月額上限を設定しておく（有料枠を使う場合）

  • 共有PCでは、APIキーの「セッションのみ」がONになっていることを確認し、利用後は設定 > 音声の「消去」を使う

  • 機密情報・個人情報を含む資料は、無料枠で送らない

  • APIキーは人に渡さない。SNSや画面共有にも映さない

  • 万一キーが漏れたかもしれないときは、Google AI Studioでそのキーを削除して、新しいキーを作る

  • Gemini Canvas のアプリを使う場合は、Geminiアプリの「アクティビティの保存」の設定を確認しておく

  • ブラウザの拡張機能を見直し、信頼できるものだけにする

  • SlideCast Studioを新しい版に更新しておく
