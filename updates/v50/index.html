はじめに・アップデート概要

SlideCast Studioを、v5.0「STAGE」に更新しました。

前回のv4.4「BLOOM」では、設定画面を作り直して、プリセットやドラッグ操作で「迷わず整えられる」ようにしました。今回の更新では、スライド・字幕・キャラをどう並べるかという「画面の舞台づくり」を中心に、ほぼすべての画面を見直しています。メジャーバージョンを上げたのは、それだけ変わったからです。

「作り始めるときに、何から決めればいいか分からない」「字幕とキャラの置き方を、毎回スライダーで探っている」「字幕をもう少しだけ“動画っぽく”したい」。そんな声に、画面の決め方から答え直した更新です。

🖱️はじめにv4.4までお使いの方へ：まずは「乗せて」試してください

大きく変わった画面を、設定を変えずに確かめられるようにしました。

今回は、分かりやすく使いやすくするために、設定画面の並びや決め方を大きく変えました。v4.4までの画面に慣れている方は、「あの設定はどこへ行ったの？」と戸惑う場面があるかもしれません。

そこで今回は、できるだけ設定を変えずに、マウスを乗せるだけでプレビューで確かめられるようにしています。

  • 字幕デザイン・吹き出しデザインの一覧
  • 画面の「型」
  • 画面切り替え効果・スライドアニメーション
  • 字幕の表示アニメーション、ステッカー・バッジ・テロップの動き
  • バッジ・テキストステッカーの形、キャラの話すときの動き
  • 色の見本・フォントの一覧

乗せている間だけプレビューが変わり、マウスを外せば元に戻ります。クリックするまでは、作品の設定は変わりません。気になる項目は、まず乗せて見比べてから選んでください。

🔎 設定の場所が分からないときは

設定画面のタブの下にある検索欄に、探したい設定の名前を入れてみてください（「設定を探しやすく、触りやすく」の章で紹介しています）。

🧩画面の型字幕とキャラの見せ方は「型」の表から選べます

画面の作りを「比率」と「型」の2つにまとめました。

これまで「見せ方」「字幕レイアウト」「書く向き」など、いくつもの項目を組み合わせて決めていた画面の作りを、「比率」と「型」の2つにまとめました。型は、見取り図の表から選びます。

  • ↔️

    横書き

    「字幕だけ」「キャラと吹き出し」「ワイプ」の3つの出し方を、「下に分ける」「重ねる（下・中・上）」の4つの置き方と組み合わせる

  • ↕️

    縦書き

    字幕だけ、または吹き出しを、右・中央・左に重ねるか、右・左に分けて置く

  • ➕

    そのほか

    左右に2人・キャラだけ・字幕なし

全部で23パターンです。新しく加わった型の例です。

  • ワイプ：セリフは字幕で出し、話しているキャラを画面の隅に大きく出します
  • キャラだけ：字幕は出さず、キャラだけを画面の下に立たせます

型を選んだあとは、余白・高さ・大きさを「小・中・大」などのボタンで整えるだけです。細かく決めたいときは「個別」で数値も指定できます。キャラの位置や大きさは、プレビュー上で掴んで動かせます。

キャラの配置は「作品ごと」に

キャラの立ち位置や大きさは、作品ごとに覚えるようになりました。ある作品で配置を変えても、ほかの作品のキャラは動きません。気に入った配置は「この配置を既定にする」で、ほかの作品でも使えます。

🧭用途から作成新しい作品は「用途から作成」で組み立てられます

ダッシュボードの「用途から作成」から、4つの手順でひと通り組み立てられます。

  1. 画面比率と型を選び、おすすめの用途から字幕の大きさなどを決める
  2. 資料スライド画像・PDF・Bundle Builder のZIPなどを入れる
  3. キャラ台本の話者ごとに、表示するキャラを選ぶ。画像やMouthLoopのzipから、その場で新しいキャラも追加できます
  4. デザインナレーションとキャラごとに、字幕・吹き出しのデザインを選ぶ

キャラを決めていないときは、仮キャラA・Bが入ります。あとから一括置換で、本物のキャラに入れ替えられます。

用途は17種類

おすすめの「用途」も、比率ごとに見直しました。名前は「YouTube」などのサービス名ではなく、見た目が分かる名前にしています。

比率用途
16:9字幕上下分割／字幕オーバーレイ／上下分割・大きい字幕／キャラのワイプ／少し上に重ねる字幕／縦書き／左右に2人（縦書き）
9:16横長スライド／縦長スライド／横長スライド・大きい字幕
1:1正方形／字幕上下分割
4:5縦長フィード／字幕上下分割
4:3字幕上下分割／上下分割・大きい字幕／縦書き
🎨字幕デザイン字幕デザインを32種にし、名前バッジを追加しました

「帯」「文字に合わせた帯」「縁取り」「影と光」の4つに分けて並べました。

字幕デザインを8種から32種に増やしました。デザインにマウスを乗せるだけで、プレビューがそのデザインに変わります。

  • 「マーカー」「下線」「角丸の帯」など、文字の幅に合わせて帯を描くデザインが加わりました
  • 吹き出しデザインも21種になり、キャラごとに別の吹き出しを選べます
  • 選んだデザインは「デザインを調整」で、文字の色・フォント・縁取り・影などを変えられます

キャラの名前バッジ

字幕や吹き出しに、話しているキャラの名前バッジを付けられるようになりました。形・背景・文字を選べるほか、名前の代わりに画像も使えます。プレビュー上でドラッグして置けます。

この作品でまとめて揃える

ナレーションやキャラごとの字幕・吹き出しの文字の見た目を、この作品の中だけ、まとめて揃えることができます。プレビューで確かめてから適用でき、元にも戻せます。

🖍️強調とカラオケ風強調とカラオケ風で、字幕を「動画らしく」

選んだ語だけ色を変えたり、読み上げに合わせて色を変えたりできます。

選んだ語だけ、字幕の色を変える「強調」

台本の表示字幕で語を選んで「強調」を押すと、その語だけ字幕の見た目が変わります。

  • 強調のスタイルは6つまで作れます。文字の色・サイズ・太さ・縁取り・マーカーなど、字幕と同じように細かく決められます
  • 横書き・縦書きの字幕、吹き出しのどれでも使えます
  • 読み上げる音声には影響しません
  • ブック型PDFの書き出しにも反映できます

読んだ所まで色が変わる「カラオケ風」

読み上げに合わせて、読んだ所まで文字の色を変える「カラオケ風」を追加しました。字幕タブの「字幕の動き」でオンにし、色は字幕デザインの「デザインを調整」→「カラオケ色」で決めます。色が変わるのは、再生中と書き出した動画です。

強調と組み合わせると、強調した語は読み上げがその語に来たときに強調の見た目になります。最初から強調が見えていて先の展開が分かってしまう、ということがありません。

字幕の表示アニメーションは22種

字幕の出方を6種から22種に増やしました。上から落ちる・ズームイン・弾む・揺れるなどの字幕ごとの動きに加えて、1文字ずつふわっと・ポップ・落ちる・ぼかしで現れる動きも選べます。

🎞️演出演出の種類を大きく増やしました

どの演出も、種類にマウスを乗せている間、プレビューでその動きを繰り返します。

項目v4.4v5.0
画面切り替え効果11種21種（向き違いを含めて30種）
スライドアニメーション13種22種
字幕の表示アニメーション6種22種
バッジ・テキストステッカーの形2種12種
  • 画面切り替え効果：扉・円形ワイプ・ブラインド・グリッチなど
  • ステッカー：登場・退場に、弾む・回りながら・めくるなどを追加。表示中の動きにも、ぴょんぴょん・ぶらさがり・点滅などを追加
  • バッジ：ステッカーと同じ「表示中の動き」を付けられるように
  • バッジ・テキストステッカーの形：四角・角丸に加えて、リボン・旗・付箋・ギザギザなど
  • テロップ：切り替え方を、フェード・めくる・タイプなど9種から選べるように
  • キャラの話すときの動き：上下・はずむ・横ゆれ・ゆらゆらなど6種から選べるように
🔎設定画面設定を探しやすく、触りやすく

設定の検索を追加し、タブと操作をそろえました。

設定の検索

設定画面のタブの下に検索欄を置きました。「帯の余白」「BGM」「APIキー」のように入れると、その設定の場所へすぐ移れます。

「画面」タブと「字幕」タブに分けました

項目が多くなっていた「基本」タブを、画面（比率・型・背景・スライド画像）と字幕（字幕デザイン・字幕の動き・強調）の2つに分けました。

操作をそろえました

  • 位置・大きさ・時間などのスライダーは、「短い・標準・長い」などのボタン＋「個別」にそろえました。今の値は、いつも項目名の隣に出ます
  • 色やフォントは、乗せるだけでプレビューできます
  • スマホ・タブレットでも、見切れた部分へ横にスクロールして届くようにしました

かんたんモードはなくしました

v4.4で入れた「かんたん／詳細」の切り替えは、今回でなくし、ひとつの画面に統一しました。大枠は「用途から作成」と段のボタンで手早く決め、細かく詰めたいときは同じ画面の「個別」で調整する形です。

🧰Bundle BuilderSlideCast Bundle Builder の更新

台本と画像づくりの手間を減らしました。

  • 台本の登場人物を、ナレーターの有無とキャラの人数で選べるように（ナレーターなしも選べます）
  • 画像生成モデルにGemini Nano Banana 2.1を追加
  • 生成した画像を、今の並び順のままZIPで保存できるように
  • 作った Bundle を「用途から作成」で読み込むと、画面比率を合わせられるように

Bundle Builder のリンクは、新しい共有URLに更新しています。

🔧改善・修正そのほかの改善・修正

細かな使い勝手と不具合を直しています。

  • 吹き出しやワイプのキャラを、絵の余白に左右されず人物の高さでそろえるように
  • 横書きの字幕の折り返しで、行頭に句読点が来ないように
  • スライド画像の拡大・位置の設定に、スナップの切り替えを追加
  • 台本で、セリフの並び替え・追加がしやすく
  • 動画スライドの設定・プレビューを改善
  • 別の端末へバックアップを復元したとき、OP/ED・自作の効果音がつながらない問題を修正
  • 画面録画などのWebM動画をOP/EDに使うと、設定を開いたときに止まる問題を修正
📌注意ご利用にあたっての注意

更新前に、次の点をご確認ください。

  • 既存の作品はそのまま開けます。型は、今までの設定から自動で決まります
  • 以前のバージョンに戻すこともできますが、v5.0で加わった設定（型・強調・新しいデザインなど）は以前のバージョンでは使えないため、見た目が変わることがあります。念のため、更新前にバックアップを作成してください
  • 用途の名前が変わりました（YouTube・TikTokなどのサービス名から、見た目の名前へ）
  • 字幕の「音声の無音に合わせる」はなくし、文字の種類に合わせて表示の時間を配分する方式にしました
  • 古い作品では、キャラのアイコンの大きさが変わって見えることがあります。画面タブの「キャラごとの調整」で直せます
  • 音声の生成・Bundle Builder の画像生成には、これまでどおりご自身のAPIキーの利用量・料金がかかります
⬆️更新手順v5.0へのアップデート方法

購入済みの方は、これまでと同じ有料noteの共有リンクからv5.0をコピーして利用できます。

💾 先にバックアップを作成

既存のプロジェクトやライブラリ、設定を引き継ぐ場合は、念のためダッシュボードの『バックアップ』からバックアップを作成してください。

GAS版を同じURLのまま更新する場合、v4.4からの差し替え対象は、v5.0の配布フォルダーにある『AppBundle.html』と『無題.html』です。既存のGASプロジェクトへ反映し、既存のデプロイを『新バージョン』として再デプロイしてください（『code.gs』と『GasAsset_』で始まるファイルは今回変更ありません）。わからなければ全部差し替えてもOKです。

GAS版の詳しいアップデート手順

ローカルHTML版を使用する場合は、『SlideCast Studio v5.0〖ローカル版〗.html』をダウンロードして開いてください。新しいGASプロジェクトや別のブラウザーで開いた場合、以前のデータは自動では表示されません。その場合はバックアップから復元してください。

🎭まとめ「どんな舞台で見せるか」から決められるように

スライドを読み上げるだけの動画から、キャラが立ち、字幕が動く「番組」へ。

v4.4「BLOOM」では、設定画面を迷わず整えられるように並べ直しました。v5.0「STAGE」では、その一歩手前の「どんな舞台で見せるか」から決められるようにしています。比率を選び、型の表から見せ方を選び、字幕デザインで雰囲気を決める。強調やカラオケ風、名前バッジで、字幕そのものにも表情を付けられるようになりました。

そのための舞台を、ひと通りそろえたつもりです。久しぶりに開いた方も、ぜひ「用途から作成」から一本作ってみてください。

今回は変更した部分が多く、開発中にも何度もバグが発生し、修正に時間がかかっています。まだ私も気づけていないバグが存在するかもしれません。不具合や「ここが分かりにくい」という点がありましたら、noteのコメントで教えていただけると助かります。
