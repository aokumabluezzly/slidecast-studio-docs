🗂️キャラ素材「アイコン画像」が「キャラ素材」になりました

登録できる画像が3つの方式に整理され、目的に合わせて選べるようになりました。

これまでキャラに登録できる画像は、実質ひとまとまりの扱いでした。実際は今までも様々な形式のアイコン素材がアップロード可能でしたが、うまく伝わっていない感じもあったので、分かりやすく整理しました。

v3.3 では 3つの方式 に分かれています。

方式登録するもの動き方向いている人
登録順静止画を複数枚話している間、登録した順に切り替わります1枚からでも使える、いちばん手軽な方式
アニメ画像GIF / アニメーションWebP / APNG を1ファイル話している間、そのアニメーションがループ再生されます既にアニメ素材を持っている方
音声連動静止画を6枚（枚数固定）ナレーションの音量に合わせて口が動きますいちばん自然。今回の目玉

🎨 素材づくりは別アプリにおまかせ

「アニメ画像」と「音声連動」の素材は、後述の Gemini Canvas アプリ「MouthLoop」で生成できます。

設定画面の上部にこの3つのタブが並んでいて、クリックで切り替えます。

💾使い勝手方式を切り替えても、前の素材は消えません

3方式の素材はそれぞれ別々に保存されるので、試して戻すのが気軽にできます。

ここが地味に大事なところです。3方式の素材は、それぞれ別々に保存されます。

  1. 「登録順」で3枚入れたまずは手軽な方式でスタート。
  2. 「音声連動」を試してみるタブを切り替えて別の方式を試します。
  3. やっぱり「登録順」に戻す最初の3枚はそのまま残っています。

✅ 入れ直し不要

切り替えのたびに素材を入れ直す必要はありません。気軽に試して、気軽に戻せます。

❓ヘルプ「？」ボタンで、その場で使い方が読めます

いま選んでいる方式の説明だけを、必要なときに開けます。

3方式のタブの右に、小さな「?」ボタンを付けました。

押すと、いま選んでいる方式の説明だけが下に開きます。全部の説明を一度に読まされないので、迷ったときだけ開けば OK です。

📦読み込み素材の入れ方が一気に楽になりました

フォルダ選択・ドラッグ&ドロップ・ZIP に対応しました。

登録手段を増やしました。どれでも使えます。

  • ファイルを複数選択（従来どおり）
  • フォルダごと選択新規
  • ドラッグ&ドロップ（ファイルでもフォルダでもOK）強化
  • ZIPファイル新規

ZIP は「登録順」と「音声連動」で使えます（1ファイルアニメでは使いません）。ZIP の中身はファイル名順に読み込まれるので、01.png〜06.png のように番号を振っておけば、そのままの順で入ります。

⚠️ 念のための上限があります

超えるとメッセージが出て、その場で止まります。

ZIP本体
50MB まで
画像枚数
200枚まで
展開後の合計
100MB まで
🖱️並べ替え並べ替えは「ドラッグ」でできます

カードを直接ドラッグして順番を入れ替えられるようになりました。

登録した画像はカード状に並びます。カードを直接ドラッグして順番を入れ替えられるようになりました。ドラッグ中は、挿入される位置にピンクの縦線が出ます。

これまで

「←／→」の矢印ボタンで1つずつ動かす必要がありました。

v3.3

カードをつかんで、入れたい位置にそのままドロップできます。

🔁 矢印ボタンも残しています

細かく1つずつ動かしたいときや、ドラッグしづらい環境では従来の「←／→」もそのまま使えます。

🎬目玉機能「音声連動」（6枚リップシンク）について

6枚の静止画を、ナレーションの音量に合わせて切り替えます。

今回の目玉です。6枚の静止画を、ナレーションの音量に合わせて切り替えます。6枚は役割が決まっていて、カードにその名前が表示されます。

  1. 目開・口閉（待機）
  2. 目開・口半
  3. 目開・口開
  4. 目閉・口閉
  5. 目閉・口半
  6. 目閉・口開

⚠️ 並び順が重要です

この順で入れてください。ZIP から読み込む場合は、この順になるようファイル名を 01〜06 で振っておくのが確実です。

差し替えは1枚ずつできます

「4枚目だけ気に入らない」というとき、画像にマウスを重ねると出てくる「差し替え」ボタンから、その1枚だけ入れ替えられます。全部やり直す必要はありません。

リップシンク間隔は「自動」推奨

口の動く速さは、標準で「自動」です。セリフごとに、音声の長さと字幕の文字量から発話速度を推定して合わせます。

まずは自動のままで試して、合わないと感じたときだけ「手動」に切り替えてスライダーで調整してください。

💬レイアウトキャラを動かすと、吹き出しが追従します

アイコンと吹き出しの相対的な位置関係が保たれるようになりました。

これまで

キャラアイコンの左右位置を動かすと、吹き出しだけがその場に取り残され、位置を変えるたびに手で合わせ直す必要がありました。

v3.3

アイコンの左右位置を動かすと、吹き出しも同じ量だけ一緒に移動します。

アイコンと吹き出しの間隔（相対的な位置関係）が保たれるので、一度きれいに配置してしまえば、あとは全体をまとめて左右に動かせます。もちろん、吹き出しだけを個別に調整することも今までどおりできます。

🪄連携ツール素材づくり用 Gemini Canvas アプリ「MouthLoop」と繋がりました

1枚の画像から、口パク用の素材を自動で作れるアプリを別途用意しました。

「6枚のリップシンク画像なんて、どうやって用意するの？」……という話になるので、素材を作るためのアプリを別途用意しました。

MouthLoop という、Google Gemini Canvas 上で動く単体アプリです。1枚の画像から、口パク用の素材を自動で作ってくれます。

  • 6枚のPNG（ZIP） → SlideCast Studio の「音声連動」にそのまま入ります
  • アニメーションWebP → 「アニメ画像」にそのまま入ります

SlideCast Studio のキャラ設定画面に「MouthLoop で素材を作る」というリンクを埋め込んであるので、そこから直接開けます。作った素材を落として、そのままドラッグするだけです。

🍵まとめおわりに

「登録順」だけでも十分実用になります。こだわりたくなったら「音声連動」へ。

今回のアップデートは、こういう方に効くはずです。

  • キャラに喋らせる動画を作っていて、口の動きをもう少し自然にしたい方
  • キャラ画像をたくさん用意していて、1枚ずつ登録するのが面倒だった方
  • キャラの立ち位置を変えるたびに、吹き出しを直すのが地味に嫌だった方

「登録順」だけでも十分実用になりますし、こだわりたくなったら「音声連動」に進む、という段階の付け方にしたつもりです。いきなり6枚用意しなくていいように、2枚からでも動くようにしてあります。

そして、その6枚を用意する手間そのものを別アプリ側に逃がしたのが今回の裏テーマです。ツールが増えるのは本来あまり良くないのですが、「画像を作る」と「動画を組む」は頭の使い方が違うので、分けたほうが結果的に速いという判断でした。

不具合や「ここが分かりにくい」という点があれば、コメントで教えていただけると助かります。いつもありがとうございます。
