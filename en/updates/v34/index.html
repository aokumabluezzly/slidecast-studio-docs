👋 OVERVIEW

To start with — what this update covers

Hello.

SlideCast Studio has been updated to v3.4 “NUANCE”.

The previous release, v3.3 “SYNC”, sorted out how character assets are registered and added audio-driven lip sync built from six images.

v3.4 takes that a step further, and is mostly a rebuild of one thing: not just moving the character’s mouth, but changing its expression and pose along with the line being spoken.

The main changes are below.

UPDATE INDEX
🎭PERFORMANCEExpressions and poses can now change partway through a line

Select some of the subtitle text and an expression and posed gesture drop in at that point.

This is the biggest addition in the release.

Select the characters in the subtitle where you want a performance, and an “Add performance” button appears.

From there you can set two things.

  • Expression
  • Posed gesture

For example:

  • Smile only on the words “thank you”
  • Change expression on a line of surprise
  • Point halfway through an explanation
  • Wave along with a greeting

That kind of direction is now possible.

Expression and pose can also be set at the same time.

Performances you have set are listed underneath the script field.

You can edit or remove them later, so you can adjust while watching the video back.

⚠️ If you rewrite the script

If you substantially rewrite the text a performance was attached to, that performance may be removed automatically, to stop it drifting to the wrong position.

📦CHARACTER ASSETSMouthLoop’s “character pack ZIP” is now supported

Load expression and gesture assets as a ZIP, instead of one image at a time.

Registering expression and gesture assets one image at a time is a lot of work, so the character pack ZIP that MouthLoop exports can now be loaded as it is.

Alongside the usual lip-sync assets, a character pack can bundle:

  • Smiling
  • Sad
  • Angry
  • Posed gestures

and more, all together.

Drop the ZIP into the asset upload field in the character settings and SlideCast Studio detects the character pack automatically.

Before it loads, you are shown:

  • The number of images
  • The size once unpacked
  • An estimate of the storage it will take
  • Which expressions it contains
  • Which posed gestures it contains

You can check all of that before registering it to the character.

⚠️ Storage

If the browser is low on free space, you get a warning.

An ordinary image ZIP and a MouthLoop character pack are told apart automatically, so there is nothing to switch on your side.

🤖AUTOMATIC PLACEMENT“Auto-acting” places expressions and gestures for you

Let it place them first, then fix by hand only the parts that bother you.

Setting a performance by hand on every single line is a lot of work, so “auto-acting” has been added too.

Turn auto-acting on, press “Place performances automatically”, and expressions and gestures are placed at the natural breaks in each line.

You can configure:

  • Which expressions and gestures to use
  • How often (sparing / standard / frequent)
  • The range (this slide / all slides)

The expressions and gestures in play can be chosen per character.

For some words — “thank you”, “a shame”, “dangerous” and the like — an expression that matches the meaning is preferred.

💰 No extra API charges

This is not a generative model reading your text. It uses built-in detection and placement rules, so there is no extra API traffic and no extra billing.

Automatically placed performances are marked “auto”.

Press “Remove automatic ones” and only the auto-placed performances go; anything you set by hand stays.

Placing them automatically first and then fixing the parts that bother you is the way to use it.

🌬️MOTIONCharacter icons now breathe and move as they speak

A small amount of movement on a still image, with no new assets needed.

Still-image character icons can now be given a little movement.

Two things were added.

  • Slow breathing while the character is silent
  • A speech bounce that follows the volume while it is talking

There are four settings.

  1. Off
  2. Subtle
  3. Standard
  4. Strong

No new image assets are required. It simply moves the image you already registered up and down a little.

Existing characters stay on “Off”, so nothing you have already made changes appearance on its own.

⚠️ How far it moves

Only the whole icon moving up and down, plus a slight stretch. It won’t tilt, and it won’t produce movement that changes the image itself, such as waving.

🗂️SETTINGS TIDY-UPCharacter settings, split into three

The list had grown too long, so it is now grouped by purpose.

There were a lot of character settings by now, so the screen has been reorganised.

Broadly, into these three.

🎨

Assets and motion

Image assets, animation, lip sync, and breathing and speech motion.

📐

Layout

The size, position and alignment of the icon and the speech bubble.

✨

Design

The icon’s shape, background, border and shadow, and the bubble colours.

As well as making things easier to find, each group can be reset to its defaults on its own.

📐LAYOUTMore control over icon and speech bubble size

Decide how big the icon and bubble are without the subtitle settings dragging them around.

Until now, changing the subtitle “area height” could pull the size of the character icon and speech bubble along with it.

In v3.4 you can choose between two ways of sizing the icon.

MethodHow the size is decided
Relative to the subtitle area (multiplier)Scales up and down with the height of the subtitle area
Relative to the screen (px)Largely unaffected by changes to the subtitle settings

The height of the speech bubble also has two options.

  • Match the subtitle area
  • Stretch to fit the amount of text

On top of that, these adjustments were added.

  • Centre-align the icon and the bubble
  • Align their bottom edges
  • Nudge just the icon in any direction
  • Set the text size per character

💡 Which one to pick

If you want to fine-tune the look of each character, go with “relative to the screen”. If you want it to feel like it always has, “relative to the subtitle area”.

Projects with older character settings keep their existing appearance as closely as possible.

👀PREVIEWThe preview while editing subtitle settings is clearer

While the subtitle settings are open, the result is shown on the canvas.

While the subtitle settings are open, a “subtitle settings preview” now appears on the editing canvas.

Change the font, text size, colour, border, shadow or subtitle area height and you can see the result right there.

If any character is tied to the subtitle area height, its name is shown as well.

That makes it easier to notice the “I only meant to adjust the subtitles, but the character icon and bubble changed too” situation.

🖼️SLIDES“Blank slides” work with no source document

Build a slide with subtitles and characters over the background, with no PDF or image.

“Add a blank slide” has been added to the add-slide menu.

A blank slide is a slide with no source material such as a PDF or image behind it.

It uses the project background, and you can place these on top of it:

  • Subtitles
  • Character icons
  • Speech bubbles
  • Captions
  • Badges and logos

With a solid or gradient background, that covers things like:

  • Title screens
  • Chapter breaks
  • Supplementary notes
  • End cards
  • Dialogue-only scenes

Set an image on a blank slide later and it becomes an ordinary image slide.

⚠️ About Ken Burns

Ken Burns is an effect applied to an image, so it does not appear on a blank slide.

Blank slides support the preview, transitions and slide-image export like any other slide.

🎞️LOADINGAnimated images load more reliably

Large GIFs and animated WebP files are easier to get in.

Handling has been improved for large animated images — GIF, animated WebP, APNG and so on.

Previously, a large file size or a high total pixel count could make the import fail.

In v3.4, images likely to exceed the memory ceiling are scaled down automatically where possible and then loaded.

When that happens, you are told the size it was reduced to.

And when an image can’t be loaded at all, the message now tells you which of these was the problem.

  • File size
  • Frame count
  • Duration
  • Image dimensions and total pixel count
🔧BUG FIXESSmaller fixes too

The fixes made after v3.3 shipped are all folded into v3.4.

Scroll jumping when typing a long script

Typing into a long script could send the script field, or the page, jumping back towards the top.

The current scroll position is now kept even while the text area resizes itself.

Notification × buttons not responding

When several notifications appeared at nearly the same time, the × button and the automatic dismissal could stop working correctly.

Notifications are now managed individually, and the × button’s click area is slightly larger.

Notification after a bulk replace

Fixed duplicate “done” notifications appearing after a bulk character replacement.

⚠️THINGS TO KNOWA note on expressions and posed gestures

Treat it as an accent on the video, not as strict lip sync.

The timing of a performance is calculated from the position of the characters you selected and the length of the audio.

It is not reading the pronunciation timings out of speech recognition, so it does not synchronise perfectly word by word.

A posed gesture plays the numbered images built in MouthLoop once, starting from the position you set.

For the short time a gesture is playing, the finished mouth shape from the pose takes priority over the usual three-level volume lip sync.

⚠️ What to expect from it

Think of it as adding a natural accent to the video, rather than as strict lip sync.

🙌IN CLOSINGIn closing

From v3.3’s “move the mouth” to v3.4’s “where, and with what face”.

v3.3 was mostly about how you register character assets and how the mouth moves.

v3.4 lets you give that character somewhat finer direction.

  • Where you want it to smile
  • Where you want a sad face
  • Which line gets a pose

You can labour over it by hand, or let “auto-acting” rough it in and then fix only the parts that need it.

Even if you aren’t making character videos, blank slides, the subtitle preview, the sizing controls and the input fixes should make things easier.
