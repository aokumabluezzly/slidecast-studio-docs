🎧 OVERVIEW

AI CODE BGM STUDIO in short

AI CODE BGM STUDIO takes the sound you describe in words and has Gemini build it as Web Audio API code. It runs inside Google’s Gemini Canvas, so there is nothing to install and no API key to supply.

You can play the result on the spot and take it away either as MP3 / WAV or as the code that plays the sound. That makes it a quick way to rough out background music and sound effects for SlideCast Studio.

⚠️ Worth saying up front

Generation is a lottery. The same prompt will not give you the same quality every time, and this is not an app that produces a finished, professional track in one shot. It works best as a way to get a usable draft quickly.

The app itself is covered in the official manual, and the product is introduced on What is SlideCast Studio?. This page is about the other side of it — preparing the audio you drop in.

🎵OverviewWhat the app does

Describe what you want, press generate, and the track plays right there.

While putting a video or an app together, you keep running into “a bit of background music would help here”, “I need a short sound effect”, or “let me at least get the mood right first”. Sitting down to actually compose something is a heavy way to answer that. This app is the light way.

Prompts can be as plain as these:

  • A field theme for an RPG set in a forest at night
  • Bright, poppy background music for a home screen
  • A short sound effect for a system notification
  • A slightly futuristic UI sound
💬

Written prompt in

Theme, purpose and mood are all you need. Every detailed setting can be left on “auto”.

🧾

Code, not a file

What comes back is the code that plays the sound, rather than a finished audio file.

🪄

Nudge it afterwards

Ask for “a little more mysterious” and it edits the current result rather than starting over.

📎

Fill in from a reference

Feed it text, an image, a PDF or a URL and it fills in genre and mood for you.

🎛️SettingsWhat you can specify

A one-line idea is enough, and so is a fully specified brief.

Type
BGM / sound effect (SE)
Length
In seconds (60 seconds or less recommended for BGM)
Genre
Game BGM, cinematic, ambient, 8-bit chiptune, EDM / trance, lo-fi hip hop, system sound effects, and more
Tempo
Slow / normal / upbeat / auto
Instruments
Piano, synth pad, strings, drums, bells and others (multiple selection)
Mood
Bright, mysterious, melancholic, tense, epic, triumphant, and more
Patterns
1 / 3 / 5 — generate that many variations at once
Also
A free-text notes field, plus auto-fill from reference material or a URL

Anything you are unsure about can be left on おまかせ (auto). Writing only the theme, listening to what comes back, and adding settings afterwards is often the faster route.

Open 「資料・URLから詳細を自動設定」(fill in details from a reference or URL) and hand it text, an image or a PDF, and it fills in the genre and mood fields for you. References are abstracted rather than copied, which suits the case where you want a similar atmosphere without reproducing the source.

🎲 Start with three patterns

Setting the pattern count to 3 gives you three different takes on the same brief at once. It finds a keeper faster than regenerating one track at a time.

💾ExportGetting the audio and the code out

Anything you like can be saved as sound, as code, or both.

  • Save the audio as MP3 or WAV
  • Download the generated code as a .js file
  • Download every pattern at once when you generated several
  • Load a downloaded file back in to preview it
  • Paste code in and apply it to play it straight away
  • Up to 20 items of history — undo and redo as far back as you need

Keeping the code alongside the audio is the point of the app. It makes the small later edits easy — nudging the volume or the length, or rebuilding the same piece at a different duration. Loop playback and volume are in the app too, so the “does this work?” check happens before anything reaches your video.

🪄RefiningNudging the result into shape

The app is built for roughing something out and then closing in on it.

A follow-up instruction is a diff against the current result, not a fresh start, so the parts you already like survive while the direction shifts.

  • Make it a little more mysterious
  • Keep the drums restrained
  • Open quietly for the first two seconds
  • End on a sense of achievement

↩️ Nothing is one-way

Undo and redo walk back through the last 20 results, so you can afford to ask for something drastic and simply step back if it overshoots.

🎬TogetherUsing it with SlideCast Studio

Trade the time you spend hunting for a track for the time it takes to make one.

SlideCast Studio lets you set background music and sound effects, but there is a common case where you have no strong preference and simply do not want to go looking for a track. That is the gap this app fills.

  1. Put the mood of the video into wordsSomething like “quiet ambient bed for a calm explainer video” — purpose plus atmosphere.
  2. Set a length and generate60 seconds or less is recommended for BGM. For a long video, a shorter loopable piece repeated in SlideCast Studio is easier to work with.
  3. Export as MP3Use the ↓ MP3 button on the playback bar.
  4. Load it into SlideCast StudioAdd it to a BGM track. Short pieces generated as sound effects also work as text-advance or slide-transition sounds.

🎵 Up to 10 BGM tracks

SlideCast Studio can layer several BGM tracks: one bed across the whole video, plus a second that only lifts the moment you want to emphasise. The official manual has the details.

⚖️CaveatsSetting expectations honestly

What it is good at, and what it is not.

To be straight about it: the app is not a magic box. Generation is a lottery, and much the same brief will give you “that one is great” one moment and “not quite” the next. That comes from Gemini generating code, and from the limits of making sound in a browser at all.

And frankly, asking any AI service “write me background music as code only, and let me download it as MP3” gets you something similar. The idea is not exotic.

What is tedious in practice is rebuilding the prompt every time, pasting the returned code somewhere, and rigging up a way to hear it. This app is that loop, packaged so you do not repeat it.

Not what it is for

Producing a finished, professional track in one shot, or music you can ship as-is.

What it is for

Getting close to the right atmosphere quickly, prototyping BGM and sound effects, and building drafts to react to.

  • You want audio that fits a video or app, fast
  • You would rather adjust an AI draft than start from silence
  • You want the result kept in a form that is easy to manage — code
  • You need background music for SlideCast Studio without a detour
