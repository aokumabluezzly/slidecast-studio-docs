🧩 OVERVIEW

Everything your video needs, prepared in one place

SlideCast Bundle Builder is a Gemini Canvas app that prepares the slides, script and audio you will later load into SlideCast Studio. Create the slides on the spot or bring your own files, work through the script and the audio, then export the whole set as a Bundle ZIP.

For audio you can use Gemini TTS, your own voice through the microphone, or both. Generate everything with AI, record everything yourself, or record just the few lines you want in your own voice.

GUIDE
🧭WORKFLOWThe shape of the whole thing

Five steps, in order. At the end you have a complete set of material to finish in SlideCast Studio.

  1. Create or upload the slidesGenerate slide images inside Canvas, or load material you already have.
  2. Generate and edit the scriptChoose the conditions that fit your purpose, then prepare the script for each slide.
  3. Generate or record the audioUse Gemini TTS, your own voice, or a mix of the two.
  4. Validate the dataCheck how the script, speakers, audio and slides refer to each other.
  5. Export the Bundle ZIPLoad the finished ZIP into SlideCast Studio, adjust the staging and the audio, then export the video.

Going back to the home screen is safe

You can return to the home screen from any step; work in progress is kept.

🖼️STEP 1Create or upload the slides

You can build a new deck from scratch, or start from material you already have.

Create them here

Give a topic, an audience and an art direction, and the slide images are generated inside Canvas.

Use your own

Load PNG, JPEG, PDF, ZIP or a folder and start from an existing deck.

If you plan to record, allow the microphone first

In Gemini Canvas the app may reload the first time you grant microphone access. If recording is on your list, finish the microphone check on the home screen before you load any material.

💬STEP 2Generate a script that fits the job

The defaults work fine, but naming your audience and your tone gets you much closer to what you actually want.

  • Target audience, plus any extra conditions
  • Script style — explanatory, persuasive and so on
  • Script length
  • 1–6 speakers and how they talk to each other
  • Reading hints, to cut down on mispronunciation
  • Subtitle ratio, line length, and lines per page
  • Output language

You can write the script with a different AI

Hand the displayed prompt and the same material to any AI you like, get script JSON back, and import it into Bundle Builder. The prompt already carries the file names and the slide order.

🔊STEP 3Generate the AI voice

Pick a voice per speaker, then generate everything at once or try one slide at a time.

  • Preview and choose a voice for each speaker
  • Generate audio for every slide at once
  • Generate or regenerate a single slide
  • Play back what has already been generated
  • Swap in a recording wherever you want one

Whether you need an API key depends on the model

The default setup works without an API key, but some models — newer ones in particular — may require a Gemini API key. Model names and availability can change.

🎤RECORDINGRecord your own voice and trim it

The script is shown on the recording screen, so reading, checking and accepting all happen in one place.

  1. RecordStart and stop while reading the subtitle script on screen.
  2. Check the waveformSee how long the take is and where the sound actually sits.
  3. Trim both endsDrag the handles to cut silence, button clicks and false starts.
  4. Preview or re-recordListen to the trimmed take and record again if it is not right.
  5. Accept itSet the take as the audio for that slide.

If the slide already has generated audio

Where Gemini TTS audio is already set, you are asked to confirm before the recording overwrites it.

📦STEP 4–5Validate, then import the ZIP

Run the pre-export check, then load the Bundle ZIP into SlideCast Studio.

The audio stays adjustable after import

Both Gemini TTS audio and your recordings can have their speed and pitch adjusted inside SlideCast Studio. The new length is reflected on the timeline, and you can always go back to the original.

⚠️BEFORE YOU STARTWorth knowing before you begin

The tool depends on Gemini’s availability and on browser permissions, so read this part first.

  • 🔒

    No confidential material

    Do not upload material containing confidential information, personal data or anything internal to your company.

  • ⏳

    Back off when limited

    Repeated 429 errors or failures usually mean a usage limit. Wait rather than retrying in quick succession.

  • 🧠

    Models change

    Model names, speed and availability for script generation and TTS can change without notice.

  • 🔑

    API key only when needed

    The defaults need none, but some models require a Google AI Studio API key.

  • 🎤

    Microphone is optional

    Allow it only if you record. AI voice alone needs no microphone access.

  • 📚

    Careful with very long decks

    A large number of slides or a very long script can fail. Split the work when it does.

Changes on Google’s side can change how this behaves

Bundle Builder is a companion tool running on Gemini Canvas. Specification changes, outages or usage limits on Google’s side can make it behave differently from what is described here.

Is it unusable if I don’t allow the microphone?
No. Everything except mic recording, Gemini TTS included, works without it.
Can AI voice and recordings be mixed?
Yes, slide by slide.
What if script generation doesn’t go well?
Use the prompt for external AI, build the script JSON elsewhere, and import it into Bundle Builder.
Where does the exported ZIP go?
Upload it to “Create from documents” on the SlideCast Studio dashboard.
