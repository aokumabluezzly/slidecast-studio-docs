🎧 OVERVIEW

このページで分かること

AI CODE BGM STUDIO は、作りたい音のイメージを言葉で書くと、Gemini が Web Audio API のコードとしてBGMや効果音を組み立ててくれるアプリです。Google の Gemini Canvas 上で動くので、インストールもAPIキーの用意も要りません。

生成した音はその場で再生でき、MP3 / WAV でも、音を鳴らすコードそのものでも持ち出せます。SlideCast Studio のBGMや効果音の当たり出しに、そのまま使えます。

⚠️ 先に言っておきたいこと

生成にはガチャ要素があります。同じ指示でも毎回同じ品質にはならず、プロ品質の完成品が一発で出るアプリではありません。「叩き台をすばやく出す道具」として使うのが、いちばん相性のいい使い方です。

SlideCast Studio 本体の使い方は 公式マニュアル、アプリそのものの紹介は SlideCast Studio とは にまとまっています。このページは、そこへ載せる音素材を用意する側の話です。

🎵概要どんなアプリか

テーマを書いて生成ボタンを押すと、条件に沿ったBGMや効果音がその場で鳴ります。

動画やアプリを作っていると「ちょっとしたBGMがほしい」「短い効果音がほしい」「雰囲気だけでも先に合わせたい」という場面が出てきます。そこで本格的な作曲に入るのは重い、というときのための道具です。

たとえば、こんな指定で生成できます。

  • 夜の森を冒険するRPGのフィールド曲
  • 明るくてポップなホーム画面用BGM
  • システム通知に使える短い効果音
  • 少し近未来感のあるUIサウンド
💬

言葉から生成

テーマ・用途・雰囲気を書くだけ。細かい設定は「おまかせ」でも進みます。

🧾

音声ではなくコード

完成した音声ファイルではなく、音を鳴らすコードそのものが出てきます。

🪄

追加指示で調整

いまの結果をベースに「もう少し神秘的に」といった最小変更ができます。

📎

資料から補完

テキスト・画像・PDF・URLを読ませて、ジャンルや雰囲気を自動で埋められます。

🎛️設定指定できること

ざっくり書いて生成しても、細かく詰めても、どちらでも使えます。

どれを選べばいいか分からない項目は、そのまま「おまかせ」で構いません。テーマ文だけ書いて生成し、出てきた音を聞いてから設定を足していく方が早いことも多いです。

「資料・URLから詳細を自動設定」を開いてテキストや画像、PDFを渡すと、ジャンルや雰囲気の欄を自動で埋めてくれます。参考情報は抽象化して反映される前提なので、「近い空気感はほしいが、そのまま再現したいわけではない」というときに向いています。

🎲 まず3パターン出すのがおすすめ

生成パターン数を 3 にすると、同じ条件で違うバリエーションが同時に出ます。1本ずつ作り直すより、当たりを見つけるのが速くなります。

💾書き出し音とコードの持ち出し方

気に入った結果は、音としてもコードとしても保存できます。

  • MP3 / WAV で音声ファイルとして保存
  • 生成コード（.js）としてダウンロード
  • 複数パターンを作ったときは一括ダウンロード
  • ダウンロードしたコードを読み込み直して再生確認
  • コードを貼り付けて適用し、そのまま鳴らす
  • 生成履歴は最大20件。元に戻す・やり直すで何段でも往復できる

音声ファイルだけでなくコードが残るのがこのアプリの特徴です。あとから少しだけ音量や長さを触りたいとき、同じ曲を別の尺で作り直したいときに扱いやすくなります。ループ再生と音量もアプリ側で確認できるので、動画に載せる前の当たり確認はここで済ませられます。

🪄調整追加指示で少しずつ寄せる

一発で決めるより、ラフを出してから詰める流れを想定しています。

追加演出指示は、いまの生成結果を土台にした差分の指示です。ゼロから作り直さないので、気に入っている部分を壊さずに方向だけ寄せられます。

  • もう少し神秘的にしたい
  • ドラムは控えめにしたい
  • 冒頭2秒は静かに入りたい
  • 最後は達成感のある終わり方にしたい

↩️ 戻せるので気軽に試せます

「元に戻す」「やり直す」で過去の生成結果に何段でも戻れます（最大20件）。行き過ぎたら戻せばいいので、思い切った指示を出して構いません。

🎬連携SlideCast Studio と組み合わせる

BGMを探す手間を、そのまま作る手間に置き換えられます。

SlideCast Studio では BGM と効果音を設定できますが、「そこまでこだわりはないけれど、素材を探すのが面倒」という場面があります。そこを AI CODE BGM STUDIO で埋める、という使い方です。

  1. 動画の雰囲気を言葉にする「落ち着いた解説動画の背景に流す、静かなアンビエント」のように、用途と雰囲気を書きます。
  2. 尺を決めて生成するBGMは60秒以内を推奨。長い動画にはループ前提の短めの曲を作って、SlideCast Studio 側で繰り返す方が扱いやすくなります。
  3. MP3で書き出す再生バーの「↓ MP3」で保存します。
  4. SlideCast Studio に読み込むBGMトラックへ追加します。効果音として作った短い音は、文字送り音や画面切り替えの音にも使えます。

🎵 BGMは最大10トラック

SlideCast Studio 側は BGM を複数トラック重ねられます。全体に敷く1本と、盛り上げたい場面だけの1本、のような組み方もできます。詳しくは公式マニュアルをご覧ください。

⚖️注意期待しすぎないための前置き

できることと、できないことをはっきりさせておきます。

正直に書くと、このアプリは万能ではありません。生成にはガチャ要素があり、同じような指示でも「今回はかなり良い」「でも次は少し違う」ということが普通に起きます。Gemini によるコード生成であることに加えて、ブラウザ上で音を作ること自体にも限界があるためです。

また、ぶっちゃけて言えば、各種AIサービスに「〇〇のBGMをコードだけで作って。MP3でダウンロードもできるようにして」と雑に頼むだけでも似たことはできます。発想として特別なわけではありません。

ただ実際には、毎回プロンプトを組み立て直したり、出てきたコードを貼り直したり、再生確認の導線を整えたりするのが地味に面倒です。そこを毎回やらなくていい形にまとめたのがこのアプリ、という位置づけです。

向いていない使い方

一発でプロ品質の完成曲を出す。納品物としてそのまま使える音楽を作る。

向いている使い方

雰囲気の近い素材をすばやく出す。試作用のBGM・SEを用意する。叩き台や当たりを作る。

  • 動画やアプリに合わせた音素材を素早く作りたい人
  • AIで叩き台を出してから微調整したい人
  • コードとして管理しやすい形で残したい人
  • SlideCast Studio 用のBGMを手早く用意したい人
